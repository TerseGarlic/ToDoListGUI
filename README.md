To-Do List App (WinForms)

A simple, clean Windows Forms-based To-Do List desktop app written in C#. Includes features like dark mode, task priority levels, due dates, persistent saving/loading, and task detail popups.

Features

✅ Add Tasks with description, priority (High/Medium/Low), and optional due date.

⬜ Mark as Complete

❌ Remove Tasks

🔄 Save/Load Tasks (locally as tasks.txt)

🌚 Dark Mode Toggle

🔍 Double-Click a Task to view details in a popup

How to Use

Run the executable (ToDoListGUI.exe) or build it via Visual Studio.

Enter a task and click "Add" (or press Enter).

Use buttons to manage tasks.

Toggle Dark Mode using the checkbox in the bottom right.

Double-click a task to see its full details.

Installation

Clone this repo or Download ZIP

Open the solution in Visual Studio (Target Framework: .NET Framework 4.x)

Build & run
